# 🍳 CookBook

CookBook is a Django-based recipe sharing platform that allows users to discover, create, manage, and share recipes. The application provides user authentication, recipe management, and an intuitive interface for organizing cooking ideas.

---

## 📌 Features

### User Management
- User Registration
- User Login & Logout
- Secure Authentication
- User Profile Management

### Recipe Management
- Create Recipes
- View Recipes
- Update Recipes
- Delete Recipes
- Upload Recipe Images
- View Detailed Recipe Information

### Additional Features
- Responsive User Interface
- Recipe Organization
- Search Functionality
- Category-Based Management

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/amProgyy/CookBook.git
cd CookBook
```

### 2. Create Virtual Environment

```bash
python -m venv venv
```

### 3. Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Linux / Mac

```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Apply Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

### 6. Run Development Server

```bash
python manage.py runserver
```

### 7. Open Browser

```text
http://127.0.0.1:8000/
```
